# スキル使用確率の計算式
注意：photon quantumの内部パラメータをhookしているので確度は高いけど、もしかしたら間違えてるかも

## 結論
- まず以下を全て加算
    - 表示上のスキル使用確率
    - 遺物「古い本」
    - 財宝「幸運のお守り」、専用財宝
    - パッシブスキル
    - パンブロッブ
- そしてギガチャドのバフ強化送信がかかっていれば全て加算された後の数字に`1.05`を乗算
> 神話ランク以上のユニットのスキル発動確率が5%増加します。

## 具体例
マスタークンの火花ひっかき、専用財宝Lv11、遺物Lv10、パンブロッブ1.97%の場合：
```
スキル使用確率 = 表示上のスキル使用確率 + 遺物「古い本」 + 財宝「幸運のお守り」|専用財宝 + パッシブスキル + パンブロッブ
スキル使用確率 =                8.00% +         1.90% +                      5.00% +            0% +       1.97%
スキル使用確率 = 16.87%
```

ギガチャドの強化送信継続中の場合は`16.87%*1.05 = 17.7135%`となる

## 例外
恐らく実装上の不備で重力弾のスキル使用確率が異常に低く計算されている。

通常  ：`表示上スキル使用確率 + 遺物 + その他バフの加算合計`
重力弾：`表示上スキル使用確率 + 遺物 + その他バフの加算合計/100`

だから例えば重力弾に幸運のお守りつけても意味ないし、専用財宝のスキル使用確率増加の部分も意味ない、パンブロッブもLv6特性も意味ない。遺物だけはなぜか1/100されていない。一応この問題は運営に報告済みなので今後の修正に期待したい。
