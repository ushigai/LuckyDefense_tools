Q. 小学生レベルでも分かる四則演算式での表示があると助かります
　A. いい感じに実装します。
Q. ウチの"嵐の眼"の扱いについて教えてください
　A. 現状、無条件で最終ダメージに最大効果8.1倍しています。可変にできるように実装予定です。で敵との距離（マス数）を入力できるようにしました。
Q. 不滅投手のdpsがこんな低いかな？と思いました
　A. 不滅投手はダメージの8割近くがストライクアウトで、さらにいうとストライクアウトの再発動に大きく依存します。ストライクアウト平均1回と比較して平均2回は1.6倍、平均3回だと2.1倍ダメージが向上します。現状の実装では仮想敵はボス2体なのでストライクアウト再発動はなし（1回固定）としていますが、確かに分かりにくいのでユーザが自由に再発動回数を入力できるように実装します。平均発動回数を入力できるようにしました。
Q. Heyyy, I love this feature it’s fantastic. Just one question how is immo batman (area one) dmg better than immo ninja at thirty k coins? This is different from what we got in discord calculation. Since Batman with only one strike out should be a lot lower than ninja.
　A. Thanks for using my DPS calculator!! By "discord calculation", do you mean this Immortal DPS&FAQ? The calculation on Discord does not reflect Bat Man's Bat UP and CRIT. Bat UP becomes 1500% at Bat UP Lv15 (Hailey is 2000%, I Am Meow is 1000%). Also, if Bomba Doll is Lv6, damage is multiplied by 1.12 even with only 5% CRIT Rate. If you take those into account, it matches the Discord calculation result (BatDPS:ninjaDPS = 1:2).
Q. How does tao have higher dps with treasure lvl nine than lvl ten
　A. That's because the SEED value is fixed. Please temporarily set Advanced Settings → SEED Randomization (DEPRECATED) to Enable, and you should see the DPS increase. That said, Lazy Taoist's Treasure Lv. 9 and Lv. 10 are almost the same in DPS because there is no skill duration increase between those Treasure levels.

  • 何かお気づきの点があればDiscord(@ushigai), X(@ushigai_sub), GitHubのissueにてお知らせください
  • 注意
    • ダメージ計算式がまだ未完成で実測よりも数%低く算出されます。なので仮想敵HP削りやダメージ実数値は信用できませんがスキルごとのダメージ割合やキャラ比較については十分役に立つと思います
    • マナの回復計算式に間違いがあり実際より究極がほんの少し多く発動するようになっています（修正予定）
    • ページを開いて長時間放置するとDPS結果が低くかなり低く表示されるバグがあるので適宜ページの更新をお願いします
  • DPS算出のロジック
    • 緑字攻撃力 = 白字攻撃力 * (力のポーション + ユニットレベル合計バフ + ペット攻撃力) * 神話強化 * (マネガン + 攻撃力バフ) * ギルド加護
    • バフ = 秘伝書 + バットor魔法使いの帽子 + その他魔法or物理ダメージ増加バフ
    • ダメージ = 対ボスバフ合計 * 対気絶バフ合計 * スキル倍率 * バフ * (白字攻撃力 + 緑字攻撃力) * パテ猫 * ダメージ量増加パッシブ
    • 仮想敵はボス2体で常に気絶中
    • 財宝などのダメージ増加全般は加算として計算（e.g. アイアンニャンv2の場合、秘伝書+魔法使いの帽子+技術強化+Lv12パッシブ+洗剤）
    • 「ダメージ量増加パッシブ」はヘイリーの異種神話数やパルスLv12パッシブなどのこと
    • キャラのモーションフレーム数は反映していなく全て基本攻撃と同じ速度で発動している
  • 要検証項目
